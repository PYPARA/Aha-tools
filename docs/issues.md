# 真机问题记录

日常用正式版（`/Applications/AhaTools.app`）时，遇到不顺手的地方随手记在这里，攒一批后集中修。修好的条目移到文末「已解决」，写上提交号。

每条写清三件事就够了：

- **现象**：看到了什么，哪里不对。
- **步骤**：怎么做会出现（在哪个应用、按了什么、输入了什么）。
- **期望**：你觉得应该怎样。

截图可以放在 `docs/screenshots/issues/`，在条目里引用。
