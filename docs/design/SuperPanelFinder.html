呼出时先看最前面的应用：是访达，就读出选中的项目（没选中时用当前窗口的文件夹），列出能对它做的事。标题显示应用和名字。

内置动作按选中的类型出现：文件夹 → 压缩目录下所有图片；图片文件 → 压缩图片、识别二维码；任何文件 → 复制路径、在终端中打开、收藏。

标「自定义」的是用户在设置里加的命令动作，例如 code {path}、cd {dir} && claude。

「我的面板」缩成底部一排小图标，仍然一点就用。↑↓ 选择，↵ 执行。
