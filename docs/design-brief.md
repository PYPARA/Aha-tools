# AhaTools 设计需求

交给 Claude 做视觉设计用。设计确认后，实现时以这里列出的尺寸和约束为准。

## 产品是什么

AhaTools 是一个只给自己用的 macOS 菜单栏工具箱，用来替代越来越臃肿的 uTools 和 eul。没有 Dock 图标，入口只有两个：

- **菜单栏**：常驻显示实时网速，点击弹出菜单。
- **搜索面板**：按 ⌥Space 唤出，输入关键词搜应用、收藏的路径和插件功能，回车打开。

以后的功能都做成插件（二维码、图片压缩、翻译、hosts 切换、截图……），每个插件有一个或几个页面，在搜索面板里打开。所以**最重要的产出是一套能让所有插件页面看起来统一的组件规范**，而不只是几张页面图。

## 要设计的内容

1. **搜索面板（主界面）**
   - 顶部搜索框，可拖动窗口。
   - 结果列表：每行有类型标记（「打开」或「功能」）、标题、副标题（路径或插件名），当前选中行高亮，支持键盘上下选择。
   - 空状态：还没输入时的提示；输入后没有结果时的提示。
   - 底部提示栏：快捷键说明；出错时显示错误。
   - 进入插件后，顶部变成「← 功能名」返回按钮，下面是插件页面。
2. **插件页面的通用组件**：工具栏（按钮和输入框）、表格或列表、状态标签（成功、警告、错误、信息）、横幅提示（带操作按钮）、说明文字、空状态、加载中。
3. **两个现有插件页面**，作为规范的示例：
   - **快捷启动 › 管理收藏**：两个按钮（添加文件/应用、添加文件夹）；一行表单（路径、名称、收藏按钮）；收藏列表，每行有名称、路径、「打开」「移除」两个按钮。
   - **热键 › 检测热键占用**：顶部是模式横幅，三种状态：
     - 独占模式已开启；
     - 等待授权，带「去授权」按钮；
     - 共享模式，带「开启独占」或「关闭独占」按钮。

     下面是一张表，四列：热键、常见用途、状态（未发现占用、被占用、系统占用、AhaTools 在用）、占用者。
4. **菜单栏图标**：已经做好，不用重新设计。左边是加粗的 ↑↓，右边两行，上行上传、下行下载，样式参照 eul。如果设计稿里要画菜单栏，按这个样子放进去就行。

## 约束

- **窗口**：720 × 460 pt，无边框，不能调整大小，置顶显示；四周目前是直角，可以提议改成圆角加半透明背景（实现上可行，但需要开启额外配置）。
- **浅色和深色模式**都要有，跟随系统切换。
- **字体**：系统字体（SF / 苹方），界面文字全部是中文。
- **键盘优先**：所有操作都要能用键盘完成，选中状态和焦点状态要明显。
- **气质**：轻、快、安静。像系统自带的工具，而不是一个花哨的 App；信息密度适中，一屏能看到 8 到 10 条结果。
- **实现方式**：React + 纯 CSS 变量，不引入 UI 组件库。设计稿最好直接给出 CSS 变量（颜色、圆角、间距、字号），代码里沿用同样的命名。
