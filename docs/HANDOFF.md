### 超级面板第二版（2026-11-03）

按 uTools 的逻辑重做，设计稿 [SuperPanelHome](design/SuperPanelHome.html) / [Finder](design/SuperPanelFinder.html) / [Text](design/SuperPanelText.html) / [Settings](design/SuperPanelSettings.html)（`gen_boards.py` 生成，图标直接取 `src/assets/icons`）。

- **匹配**：`superpanel::build` 不再写死插件动作，改为 `Registry::context_matches`：文字按清单 `match.text` / `minLength` / `regex`，文件复用搜索面板的 `content_results`（压缩展开一层目录、二维码识别只收一张图片），都尊重插件详情的「自动匹配」开关。文件类匹配没有自带输入时传 `{"paths": [...]}`。每个网页应用一项「问 …」，网址多「在浏览器中打开」。之后是 AhaTools 自带的「文件」/「文字」操作和「自定义动作」，`Entry.group` 分组、`Entry.icon` 指定线条图标。
- **不自动翻译**：呼出时不发请求，「翻译」一项注明「点按后翻译」，点了才进入翻译页并带入文字。
- **固定**：搜索面板右键菜单加「固定到超级面板 / 从超级面板移除」（`superpanel_toggle_pin`，去掉输入、名字用功能全名、最多 12 个）。超级面板里右键匹配的功能可固定，并有「插件设置…」；右键固定格子「移到最前」（`superpanel_pin_first`）/「从超级面板移除」。面板内菜单是页面绘制的，不用原生菜单，避免失焦收起。末尾「固定」格子打开搜索面板，并显示提示「右键任意结果，选「固定到超级面板」」（`panel-flash` 事件）。
- **窗口**：宽 300，高度随内容。显示时先按 460 放到鼠标旁，页面用 ResizeObserver 上报自然高度（`superpanel_resize`），再按记下的鼠标位置重新放置，最多 460，中间可滚动。
- **布局**：首页四列、名字用全名（旧配置里的「二维码」显示为「生成二维码」）；有上下文时底部「我的面板」一行五格带名字，超过 5 个时显示前 4 个和「全部 N」，切到完整网格，esc / 返回回到动作。选中文字时顶部两行原文。键盘 ↑↓ 选择（网格 ↑↓ 跨行）、↵ 执行。
- **设置页**：三行卡片（呼出热键、长按右键、匹配的功能 → 已安装插件）；我的面板改成八列网格，拖动排序、悬停 ×、⌥← / ⌥→ 移动、Delete 移除，末尾「添加」打开原来的搜索选择器；自定义动作行显示适用类型、开关和「更多」（编辑 / 删除）。
- **假数据**：`?view=super&superMock=home|folder|file|image|multi|text|url|permission`、`&pins=12`；新增 `superpanel_toggle_pin` / `superpanel_pin_first` / `superpanel_resize` 模拟，`window.__superHeight` 可查看上报的高度。
- 验证：`cargo test` 122 项通过、5 项跳过（新增固定切换与清单匹配测试），`bun test` 41 项、`bun run build` 通过。浏览器核对首页 / 12 项 / 访达 / 选中文字 / 网址、「全部」切换与 esc 返回、右键固定、键盘执行、设置页拖动与键盘排序、「更多」菜单，浅色和深色；无控制台错误。

### 翻译密钥改存本地（2026-11-03）

作者决定不用系统钥匙串：没有固定签名时，每次重新打包都会弹钥匙串授权。密钥改存 `~/Library/Application Support/com.ahatools.app/translate-keys.json`（`{ "<配置 id>": "<key>" }`，权限 600），仍不进 `config.json`、不回传前端。去掉 `keyring` 依赖，`translate.rs` 的 `LocalSecrets` 实现原 `Secrets` 接口，保存 / 删除的回滚逻辑不变；文件损坏按没有密钥处理，提示重新填写。没有从钥匙串迁移：之前在调试版存过的密钥需要在翻译设置里重填一次，旧钥匙串项（service `com.ahatools.app`）可在「钥匙串访问」里手动删除。设置页说明和设计稿注释改为「保存在本机」。`cargo test` 120 项通过、5 项跳过，`bun test` 41 项、`bun run build` 通过；浏览器核对翻译设置页深浅色。

### 复审修复：二维码之后的功能（2026-11-02）

复审了从二维码开始的全部实现，修了 4 处：

- 超级面板自定义动作：从访达启动的 App 只有 `/usr/bin:/bin:/usr/sbin:/sbin`，`code {path}` 会找不到命令。执行前补上 `/opt/homebrew/{bin,sbin}`、`/usr/local/{bin,sbin}`、`~/.local/bin`、`~/bin`，已有 PATH 的顺序不变（`superpanel_commands::command_path`）。
- 读取选中文字的 ⌘C 回退：超过 150ms 才完成的复制，之前会覆盖用户剪贴板；现在后台再等 1 秒，只撤销紧接着的那一次复制。VS Code 及其衍生编辑器无选区时复制整行，会带 `isFromEmptySelection:true` 标记，现在识别后按「没有选中文字」处理。
- 超级面板定位改用 AppKit 坐标（`window_position::place_at_cursor`），不再混用 Tauri 物理坐标，修复缩放比例不同的多屏错位。光标位置在呼出时读取。
- 翻译：去掉会截断长输出的 180 秒整体请求超时；流式阶段任何数据（含推理增量、心跳）都会重置 60 秒空闲计时，另设 15 分钟上限。

`cargo test` 119 项通过，`bun test`、`bun run build` 通过。待真机确认：正式打包后从访达启动，运行「用 VS Code 打开」；在 VS Code 无选区时长按右键或按超级面板热键，应显示「我的面板」而不是当前行；两块缩放不同的屏幕上呼出超级面板的位置；用推理模型或长文本翻译不再中途超时。

- PNG 用 imagequant + png + oxipng，JPEG 用 mozjpeg，WebP 用 webp。保持尺寸、透明通道，先校正方向再移除拍摄信息，保留 ICC 和必要的 PNG 色彩块；动画 PNG/WebP、GIF、SVG 跳过。读取上限 128 MiB、解码像素内存上限 256 MiB，单张失败不影响其他图片。
- 若输出不小于原图，复制原始字节到输出目录，显示「已是最小，保留原图；拍摄信息未移除」；即使开启转 WebP，也可能保留原格式。
- 覆盖前确认，只处理确实缩小且格式未变的结果；比对原文件身份、修改时间、长度及快照字节，变化时要求重新导入；用同目录暂存文件原子替换。PNG/JPEG 转 WebP 只允许另存或复制。另存命名 `name.min.ext`，重名时用 `name.min.2.ext` 等；输出缓存也自动避免同名冲突。
- 复制使用 NSPasteboard file URL 列表，复制的是文件；⌘C 在没有文字选区且未编辑输入框时复制当前批次所有可用结果。逐行复制可在完成后立即使用，批量按钮等待整批完成；导出失败逐行提示，保留结果供重试。
- 临时数据仅位于 `~/Library/Caches/com.ahatools.app/compress/<batch_id>/{originals,output}/`，重压可以引用旧批次原始快照，运行中不淘汰批次；下次启动仅清空 compress 专用缓存。没有新增配置或持久化文件列表，最近使用 / 固定仍只保存功能入口。
- `compress-progress` 使用逐项版本号；前端先订阅后加载快照，避免过期响应回退状态。浏览器假数据在 `src/dev-mock.ts`：`?compressMock=empty|mixed|slow|error`、`?compressOpen=cancel|error`、`?compressConfirm=cancel`、`?compressExport=error`；可用 `window.__AHATOOLS_COMPRESS_MOCK__.drop(paths)` 模拟原生路径拖放，`drop(['/预览/图片'])` 模拟一级目录导入。浏览器 DOM 文件对象没有原生绝对路径，真实本地文件请在 AhaTools 中导入。
- 浏览器已核对导入不重复、搜索页先选动作、参数新建批次、多批排队、离开后恢复、监听清理、快捷键选区保护、取消 / 错误恢复及深浅色的 880×580 / 600×400。因本机 1420 已有开发服务，本工作树验收使用独立的 `bun run dev --port 5187`，未操作其他开发进程。 合并回归另行核对了目录张数、调参重压、转码覆盖限制、复制所有、后台队列与恢复，以及二维码 WebP 拖放、Hosts 离页保护、翻译输入和系统监控菜单。

## 已知问题与技术债

都不影响日常使用，前两项在发布正式版时最容易碰到。

| 问题 | 影响 | 建议处理 |
| --- | --- | --- |
| 正式版只有本机自签名证书，没有苹果开发者签名和公证 | 只能在作者这台电脑上用；换电脑或证书丢失后要重新授权「辅助功能」 | 用 `bun run release` 打包，证书在 `~/Library/Application Support/AhaTools Signing/`，别删 |

| 拼音多音字只取常用读音 | 例如「音乐」只认 yinle | 需要时改用多音字全部读音 |
| 只有资源目录里有 .icns 的应用能显示真实图标 | 图标只放在 Assets.car 里的应用显示首字占位 | 改用 NSWorkspace 取图标 |

## 接手指南

### 运行

```bash
bun install
bun run tauri dev
```

- 改 `src/`、`plugins/` 下的前端代码会热更新；改 `src-tauri/` 下的 Rust 代码会自动重新编译并重启应用。

- 前端测试：在项目根目录运行 `bun test`，覆盖二维码、图片压缩、翻译和系统监控。

### 添加一个插件

1. 新建 `plugins/<id>/plugin.json`，每个功能的 `cmds` 是搜索关键词。
2. 每个功能写一个页面 `plugins/<id>/<View>.tsx`，只从 `@ahatools/sdk` 引入宿主接口和图标；页面可以调用 `setStatus` 往底栏右侧写文字，用 `openFeature({ plugin, feature, input?, content? })` 携带文字或本次图片 / 文件输入切换页面。
3. 在 `src/views.ts` 里登记页面（键为 `"<id>/<功能 code>"`）；功能图标按 specs 第 0 项生成到 `src/assets/icons/` 即自动登记，优先匹配 `<id>-<功能 code>.svg`，再匹配 `<id>.svg`。不需要页面、选中就直接执行的功能登记在 `actions`；插件有自己的设置时，写一个设置组件登记在 `pluginSettings`，会出现在插件详情的「设置」页签。页面右上角的按钮用 `<PageActions>` 放。
4. 在 `src-tauri/src/plugins/mod.rs` 的 `BUILTIN_MANIFESTS` 里加上这个 `plugin.json`。
5. 需要原生能力时，加 `src-tauri/src/plugins/<id>.rs` 并在 `lib.rs` 注册命令；要往每次搜索里贡献结果，就实现 `SearchProvider` 并在清单里设 `"searchProvider": true`。

### 关键约束和坑

- 所有命名统一用 AhaTools，不用 aha，避免和本机另一个 Aha 应用（bundle id `app.aha.desktop.next`，数据在 `~/Library/Application Support/aha*` 和 `~/.aha-next`）混淆。bundle id 是 `com.ahatools.app`，程序名 `ahatools`，插件接口别名 `@ahatools/sdk`。
- 数据只存在 `~/Library/Application Support/com.ahatools.app/`（`config.json`、`launcher.json`、`usage.json`、`window.json`、`webapps.json`、`hosts.json`、`hosts.original`、`translate-keys.json`，以后的外部插件放 `plugins/`）；应用图标缓存在 `~/Library/Caches/com.ahatools.app/icons`；网页缓存在 `~/Library/Caches/com.ahatools.app` 和 `~/Library/WebKit/com.ahatools.app`，由系统自动生成。不要在用户主目录下建隐藏文件夹。改 bundle id 会换数据目录，`config.rs` 里有从旧目录 `com.aha.tools` 一次性迁移的逻辑。
- 菜单栏图标刷新必须用 `set_icon_with_as_template`：`set_icon` 会丢掉模板标记，图标在深色菜单栏上变成黑字看不见。
- 独占热键用的是事件拦截，需要「辅助功能」权限；没授权时自动退回共享模式，授权后无需重启即可切换。从终端跑 dev 时，权限会算到启动它的终端程序头上。
- 热键检测只能发现独占注册的热键和系统快捷键，见「已知问题」。
- 菜单栏应用没有自己的应用菜单，⌘Q 等快捷键要在页面里自己处理（弹出面板里已处理 ⌘Q）。面板的 esc、⌘, 等快捷键监听在 window 上（`App.tsx`），不要挂在某个元素上，否则没有聚焦输入框的页面收不到。
- 搜索、菜单弹窗和超级面板三个本地窗口都采用透明无边框，圆角和底色由页面自己画（`.panel`、`.settings`、`.popover`、`.super-panel`）。菜单弹窗由独立的 `.popover-content` 测量自然内容高度，通过 `menu_resize` 更新 `popover.rs` 的 `CONTENT_HEIGHT`；720 仅作为前端尚未上报时的初始高度。`window_position.rs` 将原生窗口限制在屏幕工作区，较矮时可滚动；不要以受限后的视口高度作为内容高度，或再给 `.popover` 设固定高度。收起菜单必须调用 `popover::hide` / `menu_hide`，同时停止弹窗采样；截图期间的可见性保护保持有效。
- 应用菜单（`lib.rs` 的 `setup_menu`）不显示，但网页里的 ⌘C / ⌘V / ⌘A / ⌘Z 靠它生效；故意没有 ⌘Q，免得在网页应用窗口里误按退出整个 AhaTools。⌘W 收起窗口，⌘R 重新加载网页应用。
- 网页应用窗口不在 `capabilities/default.json` 的窗口列表里，外部网站调用不了 AhaTools 的任何命令；加新窗口时保持这一点。
- 新界面先在设计稿上画，再按 [design-system.md](design-system.md) 实现：选中和悬停用暖灰，不用强调色铺底。
- 代按的按键事件带有标记（`tap.rs` 的 `SYNTHETIC_MARK`），拦截回调见到标记直接放行，否则 AhaTools 会拦住自己发出的按键。
- 录制热键时调用 `hotkey_set_recording` 暂停所有全局热键（`HotkeyRecorder` 组件已处理），否则正在录的组合键会被触发或吞掉。结束录制会从 config.json 重新注册，和保存新热键可能同时发生，所以两者都在 `hotkey/mod.rs` 的 `APPLYING` 锁里执行。录制时组合键由事件拦截（`tap.rs`）直接捕获并发出 `hotkey-recorded` 事件，不依赖网页能否收到按键（实测网页收不到）；没装拦截时才退回网页的 keydown。面板隐藏时 `stop_recording` 会结束录制，否则所有热键（包括 ⌥Space）会一直暂停。终端里的 `[hotkey]`、`[config]` 日志可以看录制和保存是否发生。
- 配置结构改动要保持旧 `config.json` 能读：`Config` 带 `#[serde(default)]`，新字段取默认值；`config.rs` 里有对应测试。

### 打包与签名

- 以后都用 `bun run release`（`scripts/release.sh`）打包，不要直接 `bun run tauri build`：后者只有临时签名，每次重打包「辅助功能」授权都会失效。
- 脚本第一次运行时生成自签名代码签名证书「AhaTools Self-Signed」（20 年有效），放在 `~/Library/Application Support/AhaTools Signing/signing.keychain-db`（单独的钥匙串文件，空密码，目录权限 700；`certificate.pem` 是公钥副本）。不放登录钥匙串、不加入钥匙串搜索列表、不设系统信任。之后每次复用同一张证书，签名的 designated requirement 是 `identifier "com.ahatools.app" and certificate leaf = H"…"`，所以重打包后授权保留。
- 证书删了或换电脑：脚本会生成新证书，正式版需要重新授权「辅助功能」等一次。
- 脚本只打 `.app`（`--bundles app`），不出 DMG：DMG 里的 App 是签名前的版本。签名后用 `ditto` 输出 `src-tauri/target/release/bundle/AhaTools-<版本>-<架构>.zip`，直接上传到 GitHub Release。不开 hardened runtime、不公证：别人下载后要在「系统设置 → 隐私与安全性」点「仍要打开」或去掉隔离属性，README 的「安装」写了步骤。
- README 的截图在 `docs/screenshots/`，是用 headless Chromium（Playwright 缓存里的 `chrome-headless-shell`，`--force-device-scale-factor=2 --virtual-time-budget=8000`）截的浏览器预览（假数据），界面变了需要重截。功能页用 `?open=<插件>/<功能>&input=…` 直接打开，例如 `?translateMock=ready&open=translate/translate&input=…`、`?open=hosts/hosts`、`?ocrMock=success`；超级面板用 `?view=super&superMock=text|folder`。
- 当前版本号仍是 0.1.0（`tauri.conf.json`、`Cargo.toml`、`package.json` 三处）。
