# AhaTools 设计规范

版本 2，2026-10-28。设计稿：[AhaTools 界面设计](https://claude.ai/artifact/MvKZXwUow89G1yPLrWDhgE)（「第二版」分组）。实现时以本文的变量为准，`src/styles.css` 里的变量名与这里一一对应。

## 气质

安静、精致、像一件做工好的工具。参考 Claude 桌面端的克制感，但保留 AhaTools 自己的身份：

- **暖色中性底**：暖调米白和暖灰，不用纯白铺满整个窗口，也不用冷灰。
- **一个强调色，省着用**：只出现在主按钮、开关打开、焦点环、链接上。选中、悬停用暖灰半透明底，不用强调色铺底。
- **结构靠留白和细线**：分组靠间距和 1px 低透明度描边，不用彩色边框、色块卡片或阴影堆叠。
- **衬线只用在标题**：页面标题、插件名、空状态的一句话用衬线；其余一律系统无衬线。
- **不照搬**：不使用 Claude / Anthropic 的品牌色（Clay 橙）、字体和标志。

## 颜色

所有颜色都是 CSS 变量；深色模式只换值，不换名字。

| 变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#FAF9F6` | `#262522` | 窗口底色 |
| `--surface` | `#FFFFFF` | `#302F2B` | 卡片、输入框、浮起的块 |
| `--sunken` | `#F3F2EC` | `#1F1E1C` | 侧栏、凹陷区域 |
| `--hover` | `rgba(120,113,100,.08)` | `rgba(255,250,240,.06)` | 悬停 |
| `--selected` | `rgba(120,113,100,.14)` | `rgba(255,250,240,.10)` | 选中行、选中导航 |
| `--border` | `rgba(40,36,30,.11)` | `rgba(255,250,240,.10)` | 分隔线、描边 |
| `--border-strong` | `rgba(40,36,30,.22)` | `rgba(255,250,240,.20)` | 输入框、按钮描边 |
| `--text` | `#1D1C1A` | `#EEEDE8` | 主要文字 |

## 字体

| 角色 | 字体栈 | 字号 / 字重 / 行高 |
| --- | --- | --- |
| 展示标题（页面标题、插件名） | `ui-serif, "New York", "Songti SC", Georgia, serif` | 22px / 500 / 1.3 |
| 小标题（区块名） | 无衬线 | 13px / 600 / 1.4，颜色 `--text-2` |
| 搜索框 | 无衬线 | 22px / 400 |
| 正文、按钮 | `-apple-system, "SF Pro Text", "PingFang SC", sans-serif` | 13–14px / 400 / 1.5 |
| 行标题 | 无衬线 | 14px / 500 |
| 说明、副标题 | 无衬线 | 12px / 400 / 1.45，`--text-2` |
| 快捷键 | `ui-monospace, "SF Mono", monospace` | 11–12px |

字间距保持 0；不使用 700 粗体；衬线标题不加粗到 600 以上。

## 间距与尺寸

- 间距只用 4 的倍数：4、8、12、16、20、24、32。
- 圆角：控件 6，行 / 卡片 10，窗口 14，胶囊 999。
- 行高：列表行 52，设置项至少 64，按钮 30（小号 26）。
- 窗口：搜索面板 760×500；进入设置或插件页时放大到 880×580。
- 菜单栏弹窗：宽 300px，高度随内容收紧；末行下保留 8px 内边距，超出屏幕工作区时纵向滚动。
- 描边一律 1px，颜色只用 `--border` / `--border-strong`。
- 阴影只用于窗口本身：`0 18px 50px rgba(30,25,15,.18)` 加一圈 `--border`。窗口内部不用阴影，分段控件选中项除外（`0 1px 2px rgba(0,0,0,.08)`）。

## 组件

- **按钮**：主按钮 = `--accent` 底 + `--on-accent` 字，一个视图最多一个；次按钮 = `--surface` 底 + `--border-strong` 描边；文字按钮 = 无底，悬停 `--hover`；危险 = 文字按钮 + `--bad` 字。禁用 40% 透明度。
- **开关**：36×22，关闭时 `--border-strong` 底，打开时 `--accent` 底；旁边如需状态，用小号文字（如「已生效」`--ok`），不用彩色色块。
- **列表行**：无描边，选中 / 悬停只换底色（`--selected` / `--hover`），圆角 10。
- **设置项**：左边标题（14/500）+ 一行说明（12，`--text-2`），右边控件；项与项之间 1px `--border` 分隔。
- **侧栏**：`--sunken` 底；导航项 34 高、圆角 8；选中项 `--selected` 底 + 文字 500，不用强调色。
- **分段控件**：`--sunken` 槽，选中段 `--surface` 底 + 细阴影。
- **胶囊**（关键词、状态）：高 24，`--accent-soft` 底 + `--accent` 字；中性状态用 `--hover` 底 + `--text-2` 字。
- **快捷键**：等宽字体，`--text-3`；在按钮里录制快捷键时显示为 `⌥ Space` 这样带空格的形式。
- **焦点**：`0 0 0 3px` 的 `--accent` 30% 透明度光环，所有可聚焦元素都要有。
- **下拉选择**：使用共享 `Select`，不用原生 select 菜单；30px 高、6px 圆角，展开层用 `--surface`、细描边、10px 圆角。选项至少 32px 高，暖灰悬停 / 选中背景，当前值有勾选标记。超过 8 项自动显示搜索，按名称、说明、分组及关键词过滤；添加热键始终提供分组搜索。翻译模型使用可手填的 `Combobox`，搜索不匹配时保留输入。展开层限制在窗口内，最高 340，空间不足时向上展开；弹层至少 240 宽（动作菜单 280），比按钮宽时向不会出界的一侧延伸，保持一边与按钮对齐，设置行里靠右的选择框即右对齐。打开长列表时滚到当前值。「添加热键」这类动作菜单的按钮不带箭头，弹层与按钮右对齐。小号 26px / 12px 字；占位文字 `--text-2`；禁用 40% 透明。菜单栏弹窗里用整行样式（左标签、右边当前值和 ›），弹层盖在内容上，不改变弹窗高度。支持方向键、回车、Esc、Tab 和输入法。静态稿：[design/Controls.html](design/Controls.html)，菜单栏展开态见 [design/SystemMonitor.html](design/SystemMonitor.html)。
- **滚动条**：所有滚动容器统一使用透明轨道，WebKit 轨道宽 8px、滑块可见宽 4px（两侧各留 2px），圆角 999px。滑块取 `--text-2` 的 40%，悬停加深为 60%，跟随深浅色；其他浏览器使用 `thin` 回退。自定义 `::-webkit-scrollbar` 会让 WebKit 放弃 macOS 叠加式滚动条：内容超出时滑块常驻显示，并占 8px 宽度，不随系统设置自动隐藏。保留拖动和横向滚动，不隐藏滚动能力。

## 图标

- 线条图标，1.6px 描边，圆头圆角，18px（行内 16px）。
- 应用显示真实图标；网页应用显示网站图标。
- **功能图标**（2026-10-29 起）：每个插件功能一个圆角方块图标，设计稿「功能图标 · 两个方向」（静态版 [design/FeatureIcons.html](design/FeatureIcons.html)）。默认用方向 A：底色从提亮 22% 渐变到压暗 14%，顶边一道渐隐高光，图形是 1.8px 白色线条加 26% 白色的浅色面（双色），圆角 11.5/48，图形占中间一半；文件在 `src/assets/icons/<key>.svg`。方向 B（浅色调底 + 彩色图形，跟随主题）是备选。同一插件的多个功能同底色、换图形。新功能先在 `docs/design/gen_boards.py` 的 `FEATURE_ICONS` 里加一项再生成，不要手画。
- 收藏的路径、界面里的小按钮仍用灰色线条图标（`--sunken` 底 + `--border` 描边的方块，或不带方块）。
- 不用 emoji 当图标。

## 动效

只在状态变化处用，时长 120–180ms，`ease-out`：悬停底色、开关滑动、窗口放大。不做弹跳和装饰性动画。

固定项拖拽：越过 5px 启动距离后，图标保留抓取偏移连续跟随指针，跟手位移不加过渡。浮起项使用 `--surface` 和 `--border-strong`，内容轻微放大至 1.035；网格以暖灰底、细虚线显示空的落点，周围项目让位和松手归位用 180ms `ease-out`。拖动到滚动区上下边缘时自动滚动，Esc 取消回原位。系统开启「减少动态效果」时保留跟手与空位反馈，关闭缩放和位置过渡。

## 文案

- 中文为主，句子短，说清楚「会发生什么」，例如「AhaTools 的热键只有它自己响应」。
- 设置项的说明写结果，不写实现。
- 按钮用动词：「收藏」「测试截图」「去授权」。
